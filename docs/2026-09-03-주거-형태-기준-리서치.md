## 1. 결론

**주거 유형이 개를 정하지 않는다. 집의 규칙과 생활 조건을 개에게 맞춘다.**

- 하드 필터는 사용자가 신고한 거주지 kg 제한(H2), 맹견 5종, 지역, 임대인 반대(H3), 만 7세 미만 아이 동거 시 입질·사나움·공격 기록 개체(L2), 이 다섯만.
- 주거 유형(H1)은 점수와 추천 이유, 체크리스트 맞춤에만 쓴다.
- 체중은 행동이 아니라 물리 제약(규약·이동)의 축으로만 쓴다.

처음 초안은 "원룸 10kg, 아파트·연립 25kg, 단독 무제한"이라는 유형별 체중 상한 하드 필터였다. 리서치 후 바꿨다. 이유 넷.

## 2. 주거 유형 분류

통계청 인구주택총조사 분류를 따른다. 생활 단위 기준이다(건물이 아니라 내가 사는 호실).

| 값 | 표시 | 포함 |
|---|---|---|
| `detached` | 단독주택 | 단독, 다가구(집 전체 거주), 타운하우스, 농가주택, 상가주택 거주층 |
| `apartment` | 아파트 | 아파트, 주상복합, LH·SH 공공임대 아파트 |
| `rowhouse` | 연립·다세대 (빌라) | 빌라, 연립, 다세대, 도시형생활주택, 반지하 포함 |
| `studio` | 원룸·오피스텔·기타 | 원룸, 오피스텔, 고시원, 기숙사, 셰어하우스, 청년안심주택 |

경계 사례

| 사례 | 분류 | 이유 |
|---|---|---|
| 넓은 오피스텔(방 2개 이상) | `studio` | 규칙 차이가 25kg 이상 개체 -2 vs -1뿐이라 영향 작음. 단순하게 유지 |
| 다가구주택 안의 원룸 한 호실 | `studio` | 생활 단위 기준 |
| 아파트 1층 전용 정원 | `apartment` | 마당은 규칙에 없음(근거 없음, 7장) |
| 주상복합 | `apartment` | 관리규약 체계 동일 |
| 시골 단독주택, 마당 있음 | `detached` | 상한 없음, 감점 없음 |
| 고시원·기숙사 | `studio` | 사육 불가 시설이 많음. H2에서 "모름"이면 체크리스트로 확인 유도 |
| 공공임대(LH·SH) | 건물 유형대로 | SH 표준관리규약상 "공동생활 피해 시 해지·퇴거" 가능(LH 계약서 조항은 미확인). H3 임대 흐름과 체크리스트로 처리 |

## 4. 규칙

### 4-1. 하드

| 조건 | 처리 | 근거 |
|---|---|---|
| `isDangerousBreed` (`kindNm`에 도사·핏불·스태퍼드셔·로트와일러 부분 일치. 맹견 5종: 도사견, 핏불테리어, 아메리칸 스태퍼드셔 테리어, 스태퍼드셔 불테리어, 로트와일러와 그 잡종) | 항상 제외, 주거 유형 무관 | 맹견사육허가제 2024-04-27 시행. 유일하게 법이 정한 크기·품종 제한. R-주거 4-2 |
| H2 `under10` 이고 `kg >= 10` | 제외 | 사용자 신고 |
| H2 `under25` 이고 `kg >= 25` | 제외 | 사용자 신고 |
| H2 상한 있고 `adultSizeUnknown` | 제외 안 함, 배지 "성견 체중 확인 필요" | 6장 |
| H3 `rent_no` | 결과 대신 안내 화면 | 사용자가 밝힌 절대 조건 |

`rent_no` 안내 화면 내용
1. 반려동물 금지 특약은 원칙적으로 효력이 있고 위반 시 해지 사유가 될 수 있다(국토교통부 2023). 계약서에 없어도 구두 합의가 계약 내용이 될 수 있다(서울서부지법 2022). [단비뉴스](https://www.danbinews.com/news/articleView.html?idxno=32387)
2. 동의를 받는 순서: 임대인에게 크기·마리 수·배상 책임을 제안하고, 동의를 문자나 특약 문구로 남긴다.
3. "동의 받았어요" 버튼으로 H3를 `rent_ok`로 바꿔 다시 시도.

### 4-2. 소프트 (주거 유형 × 개)

| H1 | 개 조건 | 점수 | 추천 이유 문구 소재 |
|---|---|---|---|
| `studio` | `kg >= 25` | -2 | "공용공간 이동 시 성인 동반·이동가방 규약 사례가 있음" |
| `apartment`, `rowhouse` | `kg >= 25` | -1 | 같은 문구 |
| `apartment`, `rowhouse`, `studio` | `kwBark` (짖음 기록) | -1 | "짖음 기록, 이웃 동의 절차 확인" |
| `detached` | 전부 | 0 | |

왜 25kg인가: 성남 A아파트 관리규약이 대형견을 25kg 이상으로 정해 성인 동반을 의무화했고, 국립축산과학원 참고치도 대형견을 25kg 이상으로 둔다. 실사용자가 부딪히는 숫자다.
왜 감점이 작은가: 체구가 행동을 예측하지 않기 때문이다(1장 근거 3). 감점은 "규약 확인 부담"의 크기만 반영한다.
왜 마당 가산이 없는가: 어떤 반환 연구도 마당·울타리를 예측 변수로 지목하지 않았다. HSUS는 "울타리 요구는 입양자 풀만 줄인다"고 한다. R-주거 3-9.

### 4-3. 경고와 체크리스트 (결과를 바꾸지 않는 주거 항목은 여기로)

| 조건 | 결과 화면 | 2주 체크리스트 |
|---|---|---|
| H2 `unknown` | 상단 경고 1줄 | 1번 "관리사무소·임대인에게 크기 제한 확인" |
| H3 `rent_unknown` | 상단 경고 1줄 | 1번 "임대인 동의를 문자나 특약으로 남기기" |
| H1 공동주택 3종 | 없음 | "직상하층·옆집 인사, 엘리베이터는 안고 타기 또는 이동가방" (서울시 준칙 제83조: 통로·복도 과반수 + 직상하층 동의, 동대문구 2026 규약 사례) |
| H1 `detached` | 없음 | "담·문 점검, 목줄 없는 외출 금지" |

## 5. 체중 구간과 출처

법정 소형·중형·대형 기준은 없다. 앱에서는 "국립축산과학원 건강관리용 참고치"라고 출처를 밝힌다.

| 경계 | 의미 | 출처 |
|---|---|---|
| 7kg | 항공 기내 반입 상한(케이지 포함, 대한항공·아시아나) | R-주거 4-1 |
| 10kg | SRT 이동장 합산 상한, 국립축산과학원 소형견 상한, 성남 규약 소형견 | R-주거 4-1, 2-3 |
| 25kg | 국립축산과학원 대형견 하한, 성남 규약 대형견(성인 동반) | 같음 |
| 32 / 45kg | 항공 위탁 상한 | 같음 |

`sizeClass`: 소형 `< 10`, 중형 `10~25`, 대형 `>= 25`. 카드 표시용이며 규칙은 `kg` 숫자를 직접 쓴다.

## 6. 체중을 판단할 수 없는 개체

`adultSizeUnknown` = 체중 미기재, 또는 `age`에 `60일미만`, 또는 출생연도가 2025~2026이고 품종이 믹스견. 공고의 24%가 60일미만이고 개의 85%가 믹스견이라 비중이 크다(R-API 9-2, 9-3).

- H2 상한이 있어도 **제외하지 않는다**. 배지 "성견 체중 확인 필요".
- 카드의 "보호소에 물을 질문"에 "부모견 크기나 성견 체중 예상은?"을 넣는다. 이 전화가 사람의 검토 1개다.
- 점수 규칙 중 `kg` 조건은 `kg`가 `null`이면 적용하지 않는다(감점도 가산도 없음).

## 7. 쓰지 말아야 할 논거

| 논거 | 왜 안 되나 |
|---|---|
| "아파트는 반려동물 금지" | 법령에 없다. 원천 금지 규약은 위법이라는 것이 통설 |
| "개 짖음이 층간소음 민원 N건" | 층간소음 이웃사이센터는 동물 소음을 접수 대상에서 제외한다. 통계가 존재하지 않는다 |

| "마당 있는 집이 안전" | 반환 예측 변수로 확인된 바 없음 |
| "혼자 4시간 넘으면 불가" | RSPCA 복지 조언에서 온 숫자. 반환 연구에서 온 게 아니고 RSPCA 본부·Dogs Trust·Battersea는 고정 숫자를 거부 |

## 8. 발표 방어

- **왜 아파트 거주자에게 25kg 개를 보여 주나?** 법·연구·인구 셋 다 유형 기반 배제를 지지하지 않는다. 대신 사용자가 아는 단지 규칙(H2)으로 자르고, 규약 확인 절차를 체크리스트로 준다.
- **하드 필터가 다섯뿐이면 매칭이 약하지 않나?** 엄격한 심사가 결과를 좋게 만든다는 증거가 없다(Weiss 2014, 30일 잔류율 96% vs 96%). 정렬 점수, 추천 이유, 보호소 질문 셋으로 같은 위험을 관리한다.
- **주거 유형은 왜 받나?** 파양 요인 중 근거가 가장 강한 축이고, 소프트 가중과 체크리스트 맞춤에 쓴다. 숫자는 사람이 아니라 개에게 붙인다(Mayhew, Petfinder 방식).
- **규칙 검증은?** 체중 파서 테스트("0,25(Kg)" 콤마, "2025(60일미만)(년생)"), 규칙 표와 LLM 이유 문장 일치 검사, 맹견 5종 제외 테스트.
