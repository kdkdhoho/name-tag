# 발표 덱 디자인 정의 (design.md)

작성 2026-09-04 김동호. `2026-09-04-발표-덱.html`의 시각 규칙 정본이다. 무엇을 말할지는 원고와 제작 규칙(`2026-09-04-발표-자료-정의.md`), 어떻게 보일지는 이 문서가 정한다. 슬라이드별 배치는 발표-자료-정의.md 제작 규칙 3장을 따르고 여기서는 반복하지 않는다.

## 1. 컨셉: 공고지

덱 전체가 한 장의 공고문이다. 배경은 종이색, 글자는 먹색, 색은 인주 하나뿐이다. 국가동물보호정보시스템 공고가 사진 한 장과 짧은 표로 아이를 소개하듯, 슬라이드도 사진·숫자·표로만 말한다. 인주는 도장 색이다. 마감·안락사·파양처럼 되돌릴 수 없는 것에만 찍는다. 정착는 먹색 pill이다. 공고번호로 불리던 아이가 14번 슬라이드에서 정착를 단다. 그 전까지 먹색 pill은 화면 왼쪽 위 HUD에만 작게 있다.

## 2. 토큰

`:root`에 그대로 복사한다.

```css
:root{
  --paper:#F4EFE6;        /* 슬라이드 배경 */
  --paper-2:#FFFDF9;      /* 공고 카드, 노트 패널: 종이 위 종이 */
  --ink:#1E1A16;          /* 본문, 제목, 큰 숫자 */
  --muted:#6B6259;        /* 보조 문장, 표 머리글, 섹션 라벨 */
  --faint:#8C8478;        /* 출처 각주, HUD */
  --line:#D9D0C2;         /* 표 구분선, 카드 테두리 */
  --vermilion:#C8371F;    /* 인주: 위험·마감·안락사·파양·감점 */
  --vermilion-bg:#F6E3DE; /* 인주 배경 tint: 경고 상자 */
  --tag:#1E1A16;          /* 정착 pill 배경 */
  --tag-ink:#F4EFE6;      /* 정착 pill 글자 */
  --serif:'Pretendard',"Apple SD Gothic Neo",sans-serif;   /* 이름은 유지, 실제 서체는 Pretendard */
  --sans:'Pretendard',"Apple SD Gothic Neo",sans-serif;
  --mono:'Pretendard',"Apple SD Gothic Neo",sans-serif;    /* 숫자는 font-variant-numeric: tabular-nums */
  --gutter:min(7vw,90px); /* 좌우 여백 */
  --r:8px;                /* 카드·배지 모서리 */
}
```

색은 이 열 개가 전부다. 새 색을 만들지 않는다. 대비는 종이 배경 기준 먹색 15:1, 보조 5:1, 인주 5:1, 흐림 3.4:1(각주 전용).

서체는 Pretendard 한 벌(2026-09-04 변경, 이전은 Noto Serif KR·Noto Sans KR·IBM Plex Mono). 변수 이름 `--serif`·`--sans`·`--mono`는 역할 구분용으로 유지하고 값은 전부 Pretendard. 굵기: 제목 900(Pretendard Black), 본문 400·500·700, 숫자·공고번호·전화번호는 500에 `font-variant-numeric:tabular-nums`. 로드는 jsDelivr 링크 하나(`https://cdn.jsdelivr.net/gh/orioncactus/pretendard@v1.3.9/dist/web/static/pretendard.min.css`)만 쓰고, 막히면 Apple SD Gothic Neo로 떨어진다.

## 3. 타이포 스케일

위계는 **Header 제목 > Body 제목 > 소제목 > 본문** 순이고, 이 순서가 뒤집히면 안 된다. 큰 숫자(3번 95,685, 5번 3열 수치, 4번 비율)와 목차 항목은 위계 밖 예외라 아래 값을 그대로 쓴다.

## 4. 색 사용 규칙

- **인주(vermilion)는 되돌릴 수 없는 것에만.** 공고 종료, 안락사, 자연사, 파양, 반환, "이미 종료", 순환 플로우의 "↺ 다시 공고로", 감점 조건, 경고 상자, 타이머 30초 이하. 슬라이드 한 장에 인주 요소는 셋을 넘기지 않는다.
- **긍정은 색이 없다.** 입양, 추천, 가점, "잘 맞는 이유"는 먹색 700으로만 굵게 한다. 초록·앰버 같은 긍정색을 두지 않는다. 종이 위에서 유일하게 튀는 색이 인주여야 경각심이 산다.
- **정착는 먹색 pill.** 정착 모양(`999px 8px 8px 999px`, 왼쪽 구멍 점)은 11번 추천 카드의 이름, 14번 클로징 두 곳에만 쓴다(HUD 뱃지는 09-04 제거). 다른 곳에 pill 모양을 쓰지 않는다.
- **muted와 faint의 경계.** 읽어야 하는 보조 문장은 muted, 있어야 하지만 읽지 않아도 되는 출처·HUD는 faint.
- 표에서 비율 숫자 색: 안락사·자연사 행은 인주, 입양 행은 먹색. 4번 슬라이드의 34.6%는 인주, 7.1%는 먹색.

## 6. 슬라이드 공통 구조

0-1번 목차부터 13번 협업과 회고까지 14장(덱 순서 2~15)은 Header, 구분선, Body, Footer 네 단으로 똑같이 짠다. 0번 표지와 14번 클로징(덱 순서 1·16)은 이 구조를 쓰지 않는다. 대상 슬라이드는 `<section class="slide std">`로 열고, 위 정렬이 필요하면 `std top`을 함께 준다.

### 6.1 구조

```
                       1280
 ┌───────────────────────────────────────────────────────────┐  y=0
 │ ▬▬▬▬▬▬ #progress 3px                                      │
 │        ↕ 30                                               │
 │ ├89.6┤ Header   .s-head > h2.s-title                      │
 │        슬라이드 제목 한 줄 (serif 900 49px)   높이 54.5   │
 │        ↕ 10                                               │
 │ ├──────── 구분선 1px --line, 좌우 여백은 본문과 같게 ────┤ │  y=95.5
 │        ↕ 18                                               │
 │        Body     .s-body > .wrap (max-width 1100)          │
 │        Body 제목 h1 → 소제목 → 본문 → 컴포넌트            │
 │        박스 높이 548.5 (글자 영역 530.5)                  │
 │        세로 가운데 정렬, .top 이면 위 정렬                │
 │                                                           │  y=644
 │        Footer   .s-foot > .foot                           │
 │        출처·근거 각주 2줄분. 높이 76 고정        16 / 16 ↘│
 └───────────────────────────────────────────────────────────┘  y=720
```

Body 높이가 모든 장에서 같아야 하므로 Header와 Footer 높이는 슬라이드마다 바뀌지 않는다. 각주가 없는 장도 `<footer class="s-foot"></footer>`를 빈 채로 둔다.

### 6.2 영역별 값

| 영역 | 클래스 | 위치·높이 | 여백 |
|---|---|---|---|
| 슬라이드 | `.slide.std` | `position:absolute; inset:0`, flex 세로 | `padding:30px var(--gutter) 0` |
| Header | `.s-head` | 위에서 30px, 높이 65.5px(제목 54.5 + 아래 여백 10 + 선 1) | 아래 `padding-bottom:10px` |
| 구분선 | `.s-head`의 `border-bottom` | y=95.5, 1px `--line`, 좌우 `var(--gutter)` | 없음 |
| Body | `.s-body` | y=95.5~644, 높이 548.5px, `flex:1 1 auto; min-height:0` | 위 `padding-top:18px` |
| Footer | `.s-foot` | y=644~720, 높이 76px 고정 | `padding:10px 0 20px`, 글자 영역 46px = 각주 2줄 |
| 슬라이드 번호 | `.hud` | 오른쪽 아래 고정 | 각주는 `var(--gutter)` 안쪽에서 끝나 겹치지 않는다 |

```css
.slide.std{padding:30px var(--gutter) 0}
.s-head{flex:0 0 auto;padding-bottom:10px;border-bottom:1px solid var(--line)}
.s-title{font:900 clamp(34px,3.8vw,52px)/1.12 var(--serif);letter-spacing:-.02em;word-break:keep-all}
.s-body{flex:1 1 auto;min-height:0;display:flex;flex-direction:column;justify-content:center;padding-top:18px}
.slide.top .s-body{justify-content:flex-start}
.s-foot{flex:0 0 auto;height:76px;padding:10px 0 20px}
```

```html
  <div class="s-body">

      <h1>모든 공고에는 종료일이 있습니다.</h1>

    </div>
  </div>
  <footer class="s-foot"><p class="foot"><span class="src">근거:</span> ...</p></footer>
  <aside data-t="...">...</aside>
</section>
```

| 영역 | 서체 | 크기 (1280 기준) | clamp | 행간 |

| Header 제목 | serif 900 | 49px | `clamp(34px,3.8vw,52px)` | 1.12 |
| Body 제목 | serif 900 | 36px | `clamp(26px,2.8vw,38px)` | 1.35 |
| Body 제목 2행 | serif 900 | 31px | `clamp(22px,2.4vw,32px)` | 1.4 |
| 소제목 | sans 700 | 26px | `clamp(20px,2vw,26px)` | 1.35 |

Header 제목 > Body 제목 > 소제목 > 본문 순서를 지킨다. 본문은 22px 아래로 내려가지 않는다.

### 6.4 Header 문구

- Header에는 슬라이드 제목만 쓴다. 문구는 제작 정의의 슬라이드 이름 그대로다: 목차 / 한 건의 공고 / 공고가 내려가는 날 / 95,685 / 열 중 넷 / 우리가 치르는 값 / 두 번 버려지는 아이 / 전환 / 정착 / 입력 1 · 결과 1 · 검토 1 / 첫 2주 체크리스트 / 같은 아이, 다른 소개 / Codex 활용과 검증 / 협업과 회고.
- **부 라벨("1부 문제" 등)은 화면에 표시하지 않는다.** 부 구분은 발표자 노트 제목에만 남는다.
- Header 제목과 Body 제목이 같은 말이 되는 장(목차)은 Body 제목을 두지 않는다.
- 이 Header가 기존 `.eyebrow`(섹션 라벨)를 대체했다. `.eyebrow` 클래스는 마크업과 스타일시트 양쪽에서 없앤다.

### 6.5 예외

| 대상 | 처리 |
|---|---|
| 0번 표지, 14번 클로징 (덱 1·16) | 4단 구조 없음. `.slide` 기본 `padding:72px var(--gutter) 76px`, `.wrap.center` 세로 가운데, 각주는 `.slide > .foot` 절대 배치 그대로 |
| 큰 숫자 3번 95,685 · 5번 3열 수치 · 4번 비율 | 3장 스케일 그대로. 위계 규칙 밖 |
| 목차 항목 | `clamp(22px,2.2vw,30px)` 그대로 |

### 6.6 넘침 처리

- 1280×720에서 어느 슬라이드도 Body 밖으로 넘치면 안 된다. `.s-body` 높이 548.5px 안에 `.wrap`이 들어가야 한다.
- 원고 문구는 줄이지도 바꾸지도 않는다. 넘치면 이 순서로 줄인다: **여백 → 행간 → 본문 폭 → Body 제목 한 단계(`h1.two`)**. Header 제목과 본문 최소 크기는 건드리지 않는다.
- 한 장에 메시지 하나. Body 제목이 곧 메시지이고, 나머지는 근거다.

## 7. 금지

- 애니메이션·전환 전부. 슬라이드 넘김은 즉시, 숫자 카운트업 없음, 진행 막대 transition 없음, hover 효과 없음.
- 그림자, 그라디언트, 반투명 겹침. 깊이는 1px 선과 종이 두 톤(`--paper`, `--paper-2`)으로만.
- 이모지, 아이콘 폰트, SVG 아이콘. 허용 글리프는 "→", "↺", "·", "①②③" 넷.
- 앰버 `#E2A24A`를 포함해 2장 밖의 색. 다크 배경.
- 배경 사진, 사진 위 글자 얹기. 강아지 사진은 카드 안에만.
- 감정 형용사에 색 입히기. 인주는 4장 목록에만.
- 슬라이드별 시간 표기, 부 구분용 간지 슬라이드.

## 9. 검수 추가 항목

제작 정의 9장 검수에 다음을 더한다.

1. 스타일시트에 `#E2A24A`, `box-shadow`, `transition`, `animation`, `linear-gradient` 문자열 0건
2. 화면에 쓰인 색 hex가 2장 토큰 열 개 안에만 있음
3. 인주색 요소가 한 슬라이드에 셋 이하
4. `.tag`(정착 모양)가 11번·14번 외에 없음
5. 폰트 차단 상태(Pretendard CDN 요청 실패)에서 1280×720 넘침 없음
6. 대상 14장(덱 순서 2~15)에 `.s-head` `.s-title` `.s-body` `.s-foot`가 각 1개, 표지·클로징에는 0개
7. `.eyebrow`가 마크업·스타일시트 양쪽에 0건, 화면 텍스트에 부 라벨("1부"~"4부") 0건
8. 1280×720에서 모든 대상 슬라이드의 `.wrap`이 `.s-body` 안에 들어감(Body 밖 넘침 0장)
