# 정착 발표 스크립트

## 한 문장

정착는 품종으로 성격을 단정하지 않고, 입양자의 생활 조건과 보호소 기록을 함께 검토해 확인해야 할 위험을 숨기지 않는 입양 보조 도구입니다.

## 5분 흐름

1. **문제, 30초** — 공고에는 사진·품종·나이·발견 정보가 주로 있고, 입양자가 자기 생활에 맞는지 판단하기 어렵다.
2. **질문, 45초** — 주거, 크기 제한, 임대 동의, 부재 시간, 동거인·동물, 활동량, 경험, 기대치, 지역의 9개 닫힌 질문을 보여 준다.
3. **추천, 90초** — 맹견·크기 제한·임대인 반대·어린 아이와 공격 기록은 하드 필터다. 나머지는 설명 가능한 규칙 점수이며, 다른 개와의 충돌·분리불안은 점수로 덮지 않고 노란 확인 플래그로 남긴다.
4. **사람의 검토, 45초** — 카드의 보호소 전화와 질문(성견 체중, 다른 개와의 반응 등)을 누르면 추천을 결정이 아니라 대화의 시작으로 만든다.
5. **첫 2주, 45초** — 임대 동의 문자, 공동주택 규약, 장시간 부재 대응, 14일차 점검까지 정착 플랜으로 연결한다.
6. **신뢰성, 45초** — fixture에서도 REST, MCP, 20개 페르소나 스모크를 같은 규칙 엔진으로 검증한다. 키나 네트워크가 없어도 데모가 멈추지 않는다.

## 데모 순서

기본 프로필로 추천을 실행한다 → 조건부 카드의 확인 플래그를 읽는다 → 전화 링크와 보호소 질문을 보여 준다 → 정착 플랜을 연다 → 임대 동의를 `임대인 반대`로 바꿔 안내 화면을 보여 준다 → MCP `evaluate_match` 결과를 보여 준다.
