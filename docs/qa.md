# Q&A 방어 카드

## 큰 개는 아파트에 맞지 않지 않나요?

체구만으로 생활 적합성을 단정하지 않습니다. 사용자가 이미 아는 관리규약·임대 조건의 크기 제한만 하드 필터로 쓰고, 공동주택이라는 사실은 설명 가능한 감점과 규약 확인 안내로 처리합니다.

## 왜 AI가 최종 추천을 하지 않나요?

근거가 보이는 규칙이 필터와 순위를 결정합니다. LLM은 규칙에서 이미 나온 이유를 문장으로 정리할 수 있을 뿐이며, 템플릿 모드에서는 키 없이도 같은 결과를 냅니다.

## 특징란 정보가 비어 있으면 어떻게 하나요?

좋은 점수로 보완하지 않고 `정보 부족` 등급으로 표시합니다. 카드에 사람·다른 개 반응을 보호소에 물을 질문으로 붙입니다.

## 공공 API나 OpenAI 키가 없으면요?

`NAMETAG_USE_FIXTURE=1`에서 네트워크를 호출하지 않고 합성 fixture로 REST, 웹, MCP를 모두 시연합니다.

## 입양자를 과하게 걸러내는 것 아닌가요?

맹견, 사용자가 아는 크기 제한, 임대인 반대, 어린 아이와 공격 기록만 제외합니다. 나머지는 조건부 추천과 확인 질문으로 남겨 사람의 판단을 보존합니다.
