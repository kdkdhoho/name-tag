# 입력 항목 구조 (개 전용, 워크숍 2026-09-04용)

작성 2026-09-03 김동호. 근거는 `2026-09-03-주거-입양-리서치.md`(이하 R-주거), `2026-09-03-리서치-API.md`(이하 R-API).

## 1. 원칙

1. **닫힌 질문으로 행동·사실을 묻는다.** 자기평가는 사람이 좋게 답한다. "활동적이세요?" 대신 "지난 7일 중 30분 이상 걷거나 뛴 날".
2. **결과를 바꾸지 않는 입력은 묻지 않는다.** 입력 1개 → 결과 1개. 결과에 영향 없는 항목은 체크리스트나 안내 문구로 뺀다.
3. **자격 심사가 아니라 매칭 정보다.** "당신은 부적격"이 아니라 "당신 조건에는 이 개들이 맞는다". 엄격한 심사가 입양 후 결과를 좋게 만든다는 증거는 없다(Weiss 2014, 30일 잔류율 96% vs 96%, p=1.0). R-주거 3-9와 6장.
4. **하드 필터는 다섯만.** 사용자가 신고한 거주지 kg 제한, 맹견 5종, 지역, 임대인 반대, 만 7세 미만 아이 동거 시 입질·사나움·공격 기록 개체. 나머지는 점수와 추천 이유.
5. 6스텝 10필드(시군구 선택, 필수 9), 1분 안에 끝난다.

## 3. 필드 상세

### H1 주거 유형 (소프트)

질문: "어떤 집에 사시나요?"

| 값 | 표시 | 포함 |
|---|---|---|
| `detached` | 단독주택 | 단독, 다가구, 타운하우스, 농가주택 |
| `apartment` | 아파트 | 아파트, 주상복합 |
| `rowhouse` | 연립·다세대 (빌라) | 빌라, 연립, 다세대, 도시형생활주택 |
| `studio` | 원룸·오피스텔·기타 | 원룸, 오피스텔, 고시원, 기숙사, 셰어하우스 |

통계청 인구주택총조사 분류를 따른다. 왜 묻나: 주거 문제는 미국 연구에서 개 파양 사유 1위(29.1%, Salman 1998), 국내외 서식 6/8이 묻는다. 그러나 유형 자체로 개를 자르지는 않는다(체구는 행동을 설명하지 않음, Morrill 2022). 규칙은 주거 기준 문서 4장.

### H2 거주지 반려동물 제한 (하드)

질문: "지금 사는 곳(관리규약·임대인)에 반려동물 크기 제한이 있나요?"

| 값 | 표시 | 규칙 |
|---|---|---|
| `none` | 제한 없음 | 상한 없음 |
| `under10` | 10kg 미만만 가능 | `kg < 10` 만 통과 |
| `under25` | 25kg 미만만 가능 | `kg < 25` 만 통과 |
| `unknown` | 모름 | 상한 없음 + 체크리스트 1번 "관리사무소·임대인에게 크기 제한 확인" |

왜 묻나: 주거 관련 입소 중 최대 하위 유형이 "품종·크기 제한" 27%(Applebaum 2024). 실제 단지는 10kg/25kg 구간으로 규제한다(성남 A아파트 관리규약, 2023). 사용자가 아는 자기 집 규칙이 우리가 추정한 유형보다 정확하다.
체중 판단 불가 개체(체중 미기재, `60일미만`, 출생연도가 올해·작년인 믹스)는 상한이 있어도 **제외하지 않고 "성견 체중 확인 필요" 배지**를 붙인다(결정 5).

### H3 자가·임대와 임대인 동의

질문: "집은 본인(가족) 소유인가요?"

| 값 | 표시 | 규칙 |
|---|---|---|
| `own` | 자가 | 없음 |
| `rent_ok` | 임대, 임대인 동의 받음 | 없음 |
| `rent_unknown` | 임대, 아직 확인 안 함 | 결과 상단 경고 1줄 + 체크리스트 1번 "임대인 동의를 문자나 특약으로 남기기" |
| `rent_no` | 임대, 임대인이 반대 | **결과 대신 안내 화면** (결정 4): 특약 효력(국토부 2023), 동의 받는 방법, 다시 시도 버튼 |

왜 묻나: 국가 표준 입양 설문지(동물보호센터 운영 지침 별지 5호) 8번 문항. 묻는 것은 지지되나 전화 검증은 효과 없음(Weiss 2014) → 묻고 안내만 한다.

### L1 평일에 집이 비는 시간 (소프트)

질문: "평일에 집에 아무도 없는 시간은 보통 몇 시간인가요?" (재택·가족 교대 포함해 실제로 비는 시간)

| 값 | 표시 |
|---|---|
| `h2` | 2시간 이하 |
| `h4` | 4시간 이하 |
| `h8` | 4~8시간 |
| `h10` | 8~10시간 |
| `h10plus` | 10시간 초과 |

ASPCA Meet Your Match 구간을 따랐다. 다만 MYM 원문의 마지막 구간은 "12시간"이고, 여기서는 "10시간 초과"로 바꿔 썼다. 국내 평균 5시간 17분(KB금융). 왜 묻나: 분리불안이 개 반환의 6.9~24%. 상한 게이트는 근거 없음 → 정렬 키로만.

### L2 동거 구성 (복수 선택)

질문: "함께 사는 사람이나 동물을 모두 골라 주세요."

| 값 | 표시 |
|---|---|
| `alone` | 혼자 삽니다 |
| `adults` | 성인 가족·동거인 |
| `child_u7` | 만 7세 미만 아이 |
| `senior65` | 65세 이상 어르신 |
| `other_pets` | 다른 반려동물 |

왜 묻나: 아이 유무와 기존 반려동물은 국내외 서식 8/8이 묻는다. 기존 동물과의 불화는 개 반환의 18.3%(Powell 2021). 아이 나이 게이트는 근거 약함 → 점수. 단, 특징란에 입질·사나움·공격 키워드가 있는 개는 아이 있는 집에서 하드 제외(안전).

### A1 활동량 (소프트)

질문: "지난 7일 동안 30분 이상 걷거나 뛴 날이 며칠인가요?"

| 값 | 표시 | 사람 활동 등급 |
|---|---|---|
| `d0` | 0~1일 | 낮음 |
| `d2` | 2~3일 | 중간 |
| `d4` | 4~5일 | 높음 |
| `d6` | 6~7일 | 높음 |

의도("산책 시킬 수 있다")가 아니라 현재 행동을 묻는다. 개 쪽 필요 활동 등급과 비교(5장).

### E1 개 양육 경험 (소프트)

질문: "개를 키운 경험이 있나요?"

| 값 | 표시 | 등급 |
|---|---|---|
| `none` | 없음 | 초보 |
| `family` | 가족이 키웠고 나는 주 양육자가 아니었음 | 초보 |
| `primary_small` | 내가 주 양육자였음, 10kg 미만 | 경험(소형) |
| `primary_large` | 내가 주 양육자였음, 10kg 이상 | 경험 |

왜 묻나: 초보에게는 성견과 중저활동 개가 맞다는 기관 의견(ASPCA, AVMA, RSPCA). 단 성견이 퍼피보다 반환이 3.4배 많다는 데이터도 있어(Powell 2021) 가중치는 작게 둔다.

### X1 첫 달 기대치 (매칭 미사용)

질문: "입양 첫 달, 배변 실수나 짖음 같은 적응 문제가 얼마나 갈 거라고 예상하세요?"

| 값 | 표시 | 체크리스트 반영 |
|---|---|---|
| `days` | 며칠이면 끝난다 | 체크리스트 첫 줄에 "입양견 78%가 입양 초기에 문제행동을 겪고, 반환의 절반은 60일 이후에 일어난다" 문구 + 2주 목표를 "적응"으로 낮춤 |
| `weeks` | 몇 주 걸린다 | 기본 체크리스트 |
| `months` | 몇 달 걸릴 수 있다 | 기본 체크리스트 + "잘 아신다" 한 줄 |

왜 묻나: 기대치가 높은 입양자가 유의하게 더 많이 반환한다(Powell 2022). 반환을 가장 잘 예측하는데 국내외 서식 8개 중 0개가 묻는다. 차별화 지점. 점수에는 넣지 않는다(결정 6).

### R1 시도, R2 시군구 (하드)

`sido_v2`, `sigungu_v2`로 동적 로드. 하드코딩 금지: 시도 목록에 `전남광주통합특별시`(6130000)가 있고 광주·전남이 따로 없다(R-API 4장). 응답에는 지역 코드가 없어 요청 파라미터 `upr_cd`, `org_cd`로 걸어야 한다. 결과 5건 미만이면 "시도 전체 보기" 버튼.

## 4. 개 쪽 파생 변수 (팀원 구현용)

R-API 9장 그대로. 전국 공고 약 2,400~2,600건이라 `state=protect`, `numOfRows=1000` 3회로 전량 받아 클라이언트에서 규칙을 돌린다. CORS 열려 있어 프록시 불필요, 이미지 URL은 `http`를 `https`로 치환.

| 변수 | 원천 | 규칙 |
|---|---|---|
| `kg` | `weight` | 공백 제거 후 `/^([\d.,]+)\(?Kg\)?/i` 매치, 콤마를 점으로("0,25(Kg)" 실존), 0·결측은 `null` |
| `birthYear` | `age` | 앞 4자리. `"2025(60일미만)(년생)"` 변형이 24% |
| `isNeonate` | `age` | `60일미만` 포함 |
| `ageApprox` | `birthYear` | `2026 - birthYear`, 최대 1년 오차 |
| `adultSizeUnknown` | 위 조합 | `kg == null` 또는 `isNeonate` 또는 (`ageApprox <= 1` 이고 품종이 믹스견) |
| `sizeClass` | `kg` | 소형 `< 10`, 중형 `10~25`, 대형 `>= 25` (국립축산과학원 건강관리용 참고치, 법정 기준 아님) |
| `needLevel` | 아래 | 낮음: `ageApprox >= 8` 또는 키워드 얌전·조용·노령·느긋·온순. 높음: `ageApprox 1~3` 이고 `kg >= 10`, 또는 키워드 활발·에너지·활동적·산책. 나머지 중간 |
| `kwGood` | `specialMark` | 사람좋아함, 사람 좋아, 순함, 순한, 경계없음, 경계 없음, 온순, 애교, 친화, 사교 |
| `kwCaution` | `specialMark` | 입질, 사나움, 사나운, 공격, 경계, 겁많, 겁이 많. 단 `kwGood`를 먼저 평가하고, `경계없음`·`경계 없음`에 걸린 `경계`는 세지 않는다(실측값 "사람경계 없음"이 양쪽에 걸림) |
| `kwBark` | `specialMark` | 짖음, 짖는, 짖어 |
| `kwSeparation` | `specialMark` | 분리불안, 혼자 못 |
| `kwOtherDogsBad` | `specialMark` | 다른 개 싫, 개 공격, 견공격 |
| `isDangerousBreed` | `kindNm` | 부분 문자열 `도사`, `핏불`, `스태퍼드셔`, `로트와일러` 중 하나 포함. 맹견 5종(도사견, 핏불테리어(아메리칸 핏불테리어 포함), 아메리칸 스태퍼드셔 테리어, 스태퍼드셔 불테리어, 로트와일러)과 그 잡종. 공고 표기가 "핏불테리어"처럼 짧을 수 있어 부분 일치로 잡는다 |

`sfeSoci`, `sfeHealth`, `etcBigo`는 실측 공란이라 쓰지 않는다. 품종은 개의 85%가 믹스견이라 행동 예측에 쓰지 않는다. 성격 신호는 전부 `specialMark` 자유 텍스트에 있다.

## 5. 규칙

### 5-1. 하드 필터 (제외)

| 조건 | 처리 |
|---|---|
| `isDangerousBreed` | 항상 제외 (맹견사육허가제, 2024-04-27 시행) |
| H2 상한 있고 `kg` 판단 가능하고 `kg >= 상한` | 제외 |
| H2 상한 있고 `adultSizeUnknown` | **제외 안 함**, 배지 "성견 체중 확인 필요" |
| L2에 `child_u7` 있고 `kwCaution` 중 입질·사나움·공격 | 제외 |
| R1/R2 | API 요청 파라미터로 처리 |
| H3 `rent_no` | 결과 화면 대신 안내 화면 |

### 5-2. 점수 (하드 통과 개체만, 기본 0)

| 입력 | 개 조건 | 점수 | 추천 이유 문구 소재 |
|---|---|---|---|
| A1 사람 등급 vs `needLevel` | 사람 ≥ 개 | +2 | "필요 활동량을 채울 수 있음" |
| | 사람이 1단계 낮음 | 0 | |
| | 사람이 2단계 낮음 | -2 | "활동량 차이 큼, 산책 계획 필요" |
| L1 `h10`, `h10plus` | `isNeonate` 또는 `ageApprox <= 1` | -2 | "어린 개는 배변·사회화에 사람 시간이 필요" |
| L1 `h10`, `h10plus` | `ageApprox >= 8` | +1 | "혼자 있는 시간에 강한 편" |
| L1 `h8` 이상 | `kwSeparation` 또는 `kwBark` | -1 | |
| L1 `h10plus` | 전체 | 상단 경고 + 체크리스트 "펫시터·산책 도우미" | |
| L2 `child_u7` | `kwCaution` 중 겁많·경계 | -1 | "아이 소음에 예민할 수 있음" |
| L2 `senior65` | `kg >= 25` 이고 `needLevel` 높음 | -1 | "산책 통제 부담" |
| L2 `other_pets` | `kwOtherDogsBad` | -2 | |
| L2 `other_pets` | 키워드 "다른 개와 잘", "사교" | +1 | |
| E1 초보 | `isNeonate` 또는 `ageApprox <= 1` | -1 | "첫 개로는 성견이 예측 가능" |
| E1 초보 | `kg >= 25` | -1 | |
| E1 초보 | `needLevel` 높음 | -1 | |
| E1 초보 | `ageApprox 2~7` | +1 | |
| E1 초보 | `kwGood` | +1 | "사람을 잘 따른다는 보호소 기록" |
| E1 경험(소형) | `kg >= 25` | -1 | |
| H1 `studio` | `kg >= 25` | -2 | "공용공간 이동 시 성인 동반 규약 사례" |
| H1 `apartment`, `rowhouse` | `kg >= 25` | -1 | 같은 문구 |
