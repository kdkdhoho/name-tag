# 유기견 입양 매칭: 기획 요약

작성 2026-09-03 김동호. 세부 근거와 API 실측은 같은 폴더의 `입력-항목-구조`, `주거-형태-기준-리서치`, `리서치-API` 문서에 있고, 이 문서는 만들 것만 적는다.

## 1. 무엇을 만드나

국가동물보호정보시스템 공고를 보는 입양 희망자에게, 그 사람의 주거 형태·생활 패턴·활동량·성격·양육 경험을 받아 가장 맞는 유기견을 추천 이유와 함께 보여 준다. 결과와 함께 입양 후 첫 2주 체크리스트와 보호소 연락처를 준다.

- 입력: 질문 10개, 1분 안에 끝난다
- 결과: 추천 개 카드 N장 (사진, 기본 정보, 잘 맞는 이유 2문장, 보호소 연락처와 전화로 확인할 질문)
- 카드 아래에 입양 후 첫 2주 체크리스트
- 대상은 개만. 매칭 규칙은 코드로 두고 LLM은 추천 이유 문장에만 쓴다

## 2. 사람에게 받는 입력

원칙 셋. 닫힌 질문으로 사실과 행동을 묻는다("활동적이세요?" 대신 "지난 7일 중 걸은 날", "차분하세요?" 대신 "쉬는 날 보내는 방식"). 결과를 바꾸지 않는 항목은 묻지 않고 체크리스트로 보낸다. 자격 심사가 아니라 매칭 정보다.

| 스텝 | 질문 | 선택지 | 쓰임 |
|---|---|---|---|
| 주거 | 어떤 집에 사시나요? | 단독주택 / 아파트 / 연립·다세대(빌라) / 원룸·오피스텔·기타 | 점수, 체크리스트 |
| 주거 | 사는 곳(관리규약·임대인)에 반려동물 크기 제한이 있나요? | 없음 / 10kg 미만만 / 25kg 미만만 / 모름 | 하드 필터 |
| 주거 | 집은 본인(가족) 소유인가요? | 자가 / 임대·동의 받음 / 임대·아직 확인 안 함 / 임대·반대 | 반대면 안내 화면, 미확인이면 경고 |
| 생활 | 평일에 집에 아무도 없는 시간은? | 2시간 이하 / 4시간 이하 / 4~8 / 8~10 / 10시간 초과 | 점수 |
| 생활 | 함께 사는 사람·동물은? (복수) | 혼자 / 성인 / 만 7세 미만 아이 / 65세 이상 / 다른 반려동물 | 점수, 아이+입질 기록은 제외 |
| 활동량 | 지난 7일 중 30분 이상 걷거나 뛴 날은? | 0~1일(낮음) / 2~3일(중간) / 4~5일(높음) / 6~7일(높음) | 점수 |
| 성격 | 쉬는 날은 주로 어떻게 보내세요? | 집에서 조용히 / 산책·운동 등 밖에서 / 사람 만나기·외출이 잦음 | 점수 |
| 경험 | 개를 키운 경험은? | 없음 / 가족이 키움 / 주 양육자·10kg 미만 / 주 양육자·10kg 이상 | 점수 |
| 기대 | 입양 첫 달, 배변 실수나 짖음이 얼마나 갈 거라 예상? | 며칠 / 몇 주 / 몇 달 | 체크리스트 문구만 |
| 지역 | 시도, 시군구(선택) | API 목록 동적 로드 | 하드 필터 |

## 3. 공고에서 쓰는 개 정보

`state=protect`(입양대상)로 전량 받아 브라우저에서 규칙을 돌린다. 지역은 요청 파라미터 `upr_cd`(시도)·`org_cd`(시군구)로 건다.

| 필드 | 쓰임 |
|---|---|
| `weight` | 체중. 문자열이라 숫자 파싱 필요(콤마 소수점 있음), 0·결측은 알 수 없음 |
| `age` | 출생연도. "60일미만" 표기로 어린 개 판정 |
| `specialMark` | 특징란 자유 텍스트. 성격 신호는 전부 여기. 긍정: 순함·사람 좋아함·경계없음·온순·애교·사교. 주의: 입질·사나움·공격·경계·겁많. 그 밖에 짖음, 분리불안, 다른 개 싫어함. 긍정을 먼저 평가하고 "경계없음"에 걸린 "경계"는 주의로 세지 않는다 |
| `kindNm` | 품종. 대부분 믹스견이라 맹견 판정에만 쓴다 |
| `careNm`, `careTel`, `careAddr` | 보호소 이름·전화·주소 |
| `noticeEdt` | 공고 마감일. 정렬 동점 처리 |
| `popfile1` | 사진. `http`를 `https`로 바꿔야 뜬다 |

개 쪽 파생값 둘. 성견 체중 판단 불가(체중 미기재, 60일미만, 1세 이하 믹스). 필요 활동 등급(낮음: 8세 이상 또는 얌전·조용·노령 키워드, 높음: 1~3세이고 10kg 이상 또는 활발·에너지 키워드, 나머지 중간).

## 4. 추천 방식

### 하드 필터 (다섯만)

1. 맹견 5종과 잡종: `kindNm`에 도사·핏불·스태퍼드셔·로트와일러 중 하나가 들어가면 제외
2. 사용자가 신고한 크기 제한 이상의 체중. 성견 체중 판단 불가 개체는 빼지 않고 "성견 체중 확인 필요" 배지
3. 지역 (API 요청 파라미터)
4. 임대인 반대: 결과 대신 안내 화면 한 장. "임대인 동의가 먼저입니다" 한 줄과 "동의 받았어요" 버튼으로 재시도
5. 만 7세 미만 아이 동거 + 특징란에 입질·사나움·공격 기록

주거 유형으로는 개를 자르지 않는다. 실제 제약은 단지 규약과 임대인에게서 나오므로 사용자가 아는 크기 제한(2번)으로 대신한다.

### 점수 (통과한 개만, 기본 0)

| 입력 | 개 조건 | 점수 |
|---|---|---|
| 활동량 | 사람 등급 ≥ 개 필요 등급 / 두 단계 낮음 | +2 / -2 |
| 집 비는 시간 8시간 이상 | 1세 이하 / 8세 이상 / 분리불안·짖음 기록 | -2 / +1 / -1 |
| 집 비는 시간 10시간 초과 | 전체 | 상단 경고 |
| 성격 | 집에서 조용히 + 필요 활동 낮음 / 밖에서 + 필요 활동 높음 / 외출 잦음 + 분리불안·겁많·경계 기록 | +1 / +1 / -1 |
| 동거: 아이 | 겁많·경계 기록 | -1 |
| 동거: 65세 이상 | 25kg 이상이고 필요 활동 높음 | -1 |
| 동거: 다른 반려동물 | 다른 개 싫어함 / 사교 기록 | -2 / +1 |
| 경험 초보 (없음·가족이 키움) | 1세 이하 / 25kg 이상 / 필요 활동 높음 | 각 -1 |
| 경험 초보 | 2~7세 / 순함·사람 좋아함 기록 | 각 +1 |
| 경험 소형견만 | 25kg 이상 | -1 |
| 주거: 원룸·오피스텔·기타 | 25kg 이상 | -2 |
| 주거: 아파트·빌라 | 25kg 이상 | -1 |
| 주거: 공동주택 3종 | 짖음 기록 | -1 |

체중을 모르는 개는 체중 조건을 가산도 감점도 하지 않는다. 정렬은 점수 내림차순, 동점은 공고 마감 임박 순. 상위 N장을 보여 준다.

추천 이유는 LLM이 쓰되 입력값은 (사람 입력, 개 정보, 적용된 규칙 목록)만 준다. 2문장. 호출이 실패하거나 규칙 목록 밖의 주장이 섞이면 그 문장은 버리고 적용된 규칙 문구를 그대로 이유로 보여 준다.

## 5. 결과 화면

카드 한 장에 다음이 들어간다.

- 사진, 품종·체중·출생연도·성별·중성화
- 잘 맞는 이유 2문장 (점수 숫자는 보여 주지 않는다)
- 배지: 성견 체중 확인 필요, 체중 미기재
- 보호소 이름·전화·주소
- 보호소에 전화로 확인할 질문 1개: 체중 미기재면 "성견 체중 예상은?", 특징란이 비었으면 "사람과 다른 개에게 어떤가?", 60일미만이면 "부모견 크기는?". 조건이 겹치면 앞의 것 하나, 해당 없으면 생략

상단 경고 1줄: 임대 동의 미확인, 크기 제한 모름, 집 비는 시간 10시간 초과. 결과가 5건 미만이면 "시도 전체 보기" 버튼.

## 6. 입양 후 첫 2주 체크리스트

결과 화면 아래에 붙인다. 순서는 크기 제한·임대 동의 확인 항목이 1~2번, 해당하는 맞춤 항목이 표 순서대로 그 뒤, 기본 항목이 마지막. 기대치 조건은 첫 줄 문구만 바꾼다.

### 맞춤 항목 (입력값 조건)

| 조건 | 항목 |
|---|---|
| 크기 제한 "모름" | 관리사무소·임대인에게 크기 제한 확인 |
| 임대·동의 미확인 | 임대인 동의를 문자나 특약 문구로 남기기 |
| 공동주택 (아파트·빌라·원룸) | 직상하층·옆집에 인사, 엘리베이터는 안고 타거나 이동가방 |
| 단독주택 | 담·문 점검, 목줄 없는 외출 금지 |
| 집 비는 시간 10시간 초과 | 펫시터·산책 도우미 알아보기 |
| 다른 반려동물 | 첫 대면은 목줄 상태로 짧게, 밥그릇·잠자리 분리 |
| 만 7세 미만 아이 | 아이와 개를 단둘이 두지 않기, 먹을 때·잘 때 건드리지 않는 규칙 |
| 기대치 "며칠" | 첫 줄에 "입양견 78%가 입양 초기에 문제행동을 겪고, 반환의 절반은 60일 이후에 일어난다"를 쓰고 2주 목표를 "적응"으로 낮춘다 |
| 기대치 "몇 달" | 기본 체크리스트 + "잘 아신다" 한 줄 |

### 기본 항목 (모두에게)

- 1~3일: 개만의 자리(방석이나 켄넬)를 정하고, 손님·외출·목욕 없이 조용히 지낸다. 사료는 보호소에서 먹던 것 그대로
- 첫 주: 밥·산책·잠을 같은 시간에. 배변 자리를 정하고 성공하면 바로 칭찬. 하루 2회 짧은 산책
- 첫 주: 동물병원 첫 검진, 동물등록(소유일부터 30일 이내)
- 2주 차: 혼자 두는 연습을 5분부터 늘리기, 이름 부르면 오기, 목줄 착용 연습
- 2주 차: 다른 개·사람·소음에 짧게 노출, 무서워하면 거리를 늘린다
- 계속: 배변 실수·짖음·무는 놀이는 정상 범위. 2주 목표는 "적응"이지 "완성"이 아니다
- 예산: 개 월평균 양육비 약 13.5만원(농식품부 2025) 한 줄

## 7. 넣지 않은 것

- 마당·울타리, 전용면적: 재파양을 예측한다는 근거가 없다
- 예산, 이사 계획, 가족 동의: 결과를 바꾸지 않으므로 체크리스트로
- 선호 품종: 공고 대부분이 믹스견
- 혼자 두는 시간 상한, 아이 나이 하한: 게이트로 쓸 근거가 없어 점수로만
- 고양이: 주거·활동량 규칙이 달라 별도 설계
